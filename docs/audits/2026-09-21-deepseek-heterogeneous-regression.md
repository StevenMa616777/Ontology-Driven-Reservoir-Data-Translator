## 真实调用发现并修复的问题

1. **约束属于哪个控制，不能只校验枚举合法。** 首轮 07/08/09 将注水井 maximum_bhp 的 control_type 写为 `bhp`，虽然枚举合法，却创建了没有 target 的新控制。selector 合同现在说明其含义，并在语义阶段检查同井已映射 target 与 constraint 的控制是否一致；错误进入有限重试，不伪造 target。
2. **季度的专用数值合同被通用分支遮挡。** 原 `_value_contract` 先处理 duration，导致 QUARTERLY 的专用示例永远不可达。现在优先给出 `value=1/source_unit=quarter/canonical_unit=day`，保留“三个月为 90 天”的口径。
3. **原文 `/bar` 是合法的倒压力写法。** 模型有时保留该写法而不是改写成 `1/bar`。增加显式等价别名，真实响应离线回放通过；未知或不兼容单位仍拒绝。
4. **PVT 必填压力必须在可重试阶段发现遗漏。** 06 的一次调用遗漏了原文明确声明的水相 300 bar 参考压力，直到 Canonical 才报错。现在 Prompt 说明常数水相模型的参考压力就是该点压力，并在语义阶段校验完整 MAPPED 点的 pressure。原文缺值应保留 UNMAPPED，不借用岩石或其他相态压力。
5. 补充“井记录中的 WATER 是井流体限定，不代表独立 PVT 模型”及井身份/类型覆盖说明。评估脚本还补齐了失败响应的 token 用量汇总。
